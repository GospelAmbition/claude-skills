Change the website, just by asking.

You don't need to know how to code. Codex makes the change, you check it on your own computer, and a teammate looks it over before it goes live.

About 2¾ minutesFor the Codex desktop appSet up · Change · Share

The steps

Set up once. After that, every change is the same few steps. Copy the messages below straight into Codex.

Once: set up

  1. Go to the repository

    Start by going to the Gospel Ambition GitHub repository at this link:

    https://github.com/ORG/REPO

    If you see a list of files, you have access. If GitHub says the page can’t be found, ask a teammate to give you access.

  2. Make a folder for the code

    Make a new folder called Gospel Ambition website. It can go anywhere; Documents is a good place. In Finder, right-click, choose New Folder, and name it.

  3. Create a Codex project

    In Codex, create a new project and choose the Gospel Ambition website folder. Do all your website work inside this project, so Codex always knows where the code is.

  4. Set approvals to Auto

    In the message box, change the approval setting to Auto. Codex can then work in this folder without stopping to ask about every small step.

  5. Clone the website’s code

    Send this message. It copies the website’s code into your folder:

    Clone https://github.com/ORG/REPO into this folder

  6. Set up gh and sign in

    gh is a small tool from GitHub that lets Codex send your changes up. Send:

    Help me set up gh

    Codex shows a short code and opens a GitHub page that says “Enter the code displayed in the app”. The code it means is the one in your Codex chat. Type it in, finish signing in, then tell Codex done.

Every change

  1. Start with a branch

    Before making any changes, create a branch for the feature. Say what you’re working on and ask for a branch:

    I’m going to work on the awareness page. Create a new branch.

    Every change gets its own branch, so you never change the live site directly.

  2. Run the website

    Run this website

    Codex gives you a link like http://127.0.0.1:8097. Open it to see the site running on your own computer. If the page says it can’t be reached, wait a moment and click reload.

  3. Describe the change

    Say what you want in plain words. For example:

    On the awareness page, add a red “Join the Awareness Team” button under the title.

    Refresh your preview and check the result. Not quite right? Keep asking until it is.

Share it

  1. Create a pull request

    Commit and create a pull request

    Codex saves your change, sends it to GitHub, and gives you a link to the pull request.

  2. Open the preview link

    Open the pull request. After a minute or two, a comment from Cloudflare appears with a Preview URL, like https://awareness-invite.dev.example.org. That’s your branch, at its own web address. Anyone can open it, so it’s the link to share.

  3. Get it reviewed and merged

    Send the pull request link to a teammate and ask them to look it over. Once it’s merged, your change is live on the main site.

    Need another change on the same branch before it’s merged? Just keep asking in the same chat, then say commit and push. The pull request and preview update.

Next time

  1. Open the project, start a new chat

    Open the Gospel Ambition website project in Codex, start a new chat, and begin at Start with a branch. If you’re unsure, ask Codex to help:

    I made a pull request for a change recently. Help me do the same thing for a new change, on a new branch.

The words, in plain English

BranchYour own copy of the code. You change the copy, never the live site.
CommitA save point: “these are the changes I made”.
Pull requestA request to bring your branch back into the main site. It comes with a preview link.
MergeBrings your changes into the main site, and they go live.
Stuck? Ask a teammate, and we’ll work through it together.
